## Brand & Style

This design system establishes a high-performance, dark-mode portfolio for a Software Engineer specializing in Machine Learning, RAG architectures, and Process Automation. The design aesthetic is a refined fusion of **Cyberpunk/High-Tech Futurism** and **Tactile Glassmorphism**, balancing deep obsidian substrates with electric crimson-ruby accents derived from the signature red plaid flannel, paired with sharp cyber-cyan/emerald telemetry cues.

### Brand Personality & Core Values
- **Calculated Precision:** Driven by algorithmic discipline, metrics, latency benchmarks, and verifiable engineering rigour.
- **Electric Energy:** High impact visual anchors using radiant crimson gradients without visual fatigue, asserting bold confidence and personality.
- **Technological Depth:** Layered translucent glass, glowing hairline vectors, and telemetry metadata communicate advanced artificial intelligence and low-level optimization.

### Target Audience & Emotional Impact
The interface targets enterprise technical recruiters, AI startup founders, research leads, and engineering directors. It evokes the feeling of interacting with an advanced neural telemetry console: responsive, impeccably organized, mathematically sound, and uncompromisingly modern.

## Colors

The color palette is built on deep carbon and obsidian grounds (`#090A0F` base, `#11131B` surface tiers), allowing high-chroma electric crimson (`#FF1E44`) to act as the primary operational hue. Secondary cyber-cyan (`#00F2FE`) and tertiary neural-emerald (`#10B981`) designate telemetry states, data pipelines, model benchmarks (e.g. F1-scores, quantization speeds), and active statuses.

### Functional Palette Structure
- **Canvas & Surfaces:**
  - Void Canvas: `#06070A`
  - Base Panel Layer: `#0E1017`
  - Elevated Container / Glass Card: `rgba(18, 22, 33, 0.65)` with specular top border `rgba(255, 255, 255, 0.08)`.
- **Primary Signals:**
  - Ruby / Crimson Core: `#FF1E44`
  - Crimson Glow: `rgba(255, 30, 68, 0.35)`
  - Crimson Accent Deep: `#9E0022`
- **Telemetry & Neural Signals:**
  - Cyber Cyan: `#00F2FE` (used for RAG pipelines, data ingestion badges, vector search indicators).
  - Neural Emerald: `#10B981` (used for positive benchmarks, quantized INT8 models, and active availability).
- **Text & Content Tiers:**
  - High-Contrast Primary: `#F9FAFB`
  - Secondary Demarcation: `#94A3B8`
  - Monospace Data / Muted Meta: `#64748B`

## Typography

The typographic hierarchy implements an engineering-grade pairing:
- **Display & Headings:** `Space Grotesk` delivers geometric precision, structural authority, and high-tech presence for project titles, hero banners, and section markers.
- **Continuous Reading:** `Hanken Grotesk` provides neutral, hyper-legible humanist-grotesque proportions for project summaries, architectural breakdowns, and professional background narratives.
- **Telemetry & Technical Signals:** `JetBrains Mono` handles metric badges, vector latency indicators, code snippets, tags (e.g. `FAISS`, `PyTorch`, `INT8`, `BETO`), and system labels.

All technical statistics (e.g., `95% INFERENCE REDUCTION`, `ROC-AUC: 0.95`, `60ms LATENCY`) must be rendered using `JetBrains Mono` to emphasize quantitative analytical engineering.

## Layout & Spacing

The layout adopts a flexible **12-column dynamic fluid grid** constrained to a max-width of `1280px` on desktop, ensuring ergonomic read-lengths for case studies while providing dense spatial metrics for ML architecture diagrams.

### Breakpoints & Adaptive Behaviors
- **Mobile (< 768px):** Single column reflow; side margin sets to `margin-mobile` (1.25rem); project metrics stack vertically with condensed `space-sm` gaps.
- **Tablet (768px - 1024px):** 6-column grid; project cards form a 2-column layout; interactive terminal modules preserve full horizontal width.
- **Desktop (1024px+):** 12-column grid; split configurations featuring project media/architecture schema (7 cols) paired with telemetry specifications and metric cards (5 cols).

Internal component breathing room follows strict 4px/8px incremental tokens (`space-xs` through `space-3xl`), maintaining visual density appropriate for developer tooling.

## Elevation & Depth

Visual hierarchy is constructed through **frosted glassmorphism**, chromatic surface isolation, and ambient laser-glow silhouettes:

### Surface & Depth Schema
1. **Canvas (Level 0):** Pure abyssal carbon (`#06070A`) with an optional ambient radial mesh gradient (`rgba(255, 30, 68, 0.05)` at top-left and `rgba(0, 242, 254, 0.03)` at bottom-right).
2. **Surface Layer (Level 1):** Solid dark card background `#0E1017` with subtle 1px border (`rgba(255, 255, 255, 0.06)`).
3. **Glass Layer (Level 2):** Translucent backdrop-filtered containers (`background: rgba(18, 22, 33, 0.65)`, `backdrop-filter: blur(16px)`, `border: 1px solid rgba(255, 255, 255, 0.08)`).
4. **Neon Hover Focus (Level 3):** On interaction, panels project a diffused ruby aura: `box-shadow: 0 12px 32px -4px rgba(255, 30, 68, 0.22), 0 0 1px 1px rgba(255, 30, 68, 0.5)`.
5. **Modal / Inspector Overlays (Level 4):** Backdrop blur of `24px` with elevated obsidian sheen (`rgba(10, 12, 18, 0.92)`).

## Shapes

The interface balances sharp industrial angles with modern softened corners (`roundedness: 2`, corresponding to `8px` default radius and `16px` for cards). 

- **Primary Cards & Containers:** `12px` to `16px` border-radius to preserve structural containment while remaining tactile and polished.
- **Telemetry Chips, Badges & Pills:** `6px` to `9999px` (fully rounded capsule) for software tags, ML frameworks, and live system status indicators.
- **Interactive Action Buttons:** `8px` radius with crisp hairline borders, avoiding circular soft forms in favor of engineered mechanical rigor.

## Components

### 1. Action Buttons
- **Primary Cyber Ruby:** Solid background gradient from `#FF1E44` to `#D61336`, white text (`Space Grotesk` medium), subtle inset highlight (`box-shadow: inset 0 1px 0 rgba(255, 255, 255, 0.25)`). On hover, expands a ruby outer glow (`0 0 20px rgba(255, 30, 68, 0.45)`).
- **Secondary Glass Ghost:** Transparent background with frosted backdrop blur, hairline border `rgba(255, 255, 255, 0.14)`. Hover transitions border to cyber-cyan `#00F2FE` with matching text color.

### 2. Telemetry Chips & ML Tags
- Rendered in `JetBrains Mono` (`label-sm`).
- Background: `rgba(255, 255, 255, 0.04)`.
- Border: `1px solid rgba(255, 255, 255, 0.08)`.
- Highlight Variants:
  - Cyan (Algorithms/Architecture: `RAG`, `FAISS`, `INT8`, `BETO`): Border `rgba(0, 242, 254, 0.3)`, text `#00F2FE`.
  - Crimson (Core Roles & Frameworks: `Python`, `FastAPI`, `Vue.js`): Border `rgba(255, 30, 68, 0.3)`, text `#FF3358`.
  - Emerald (Live Metrics & Quantization): Dot pulse with `#10B981` text.

### 3. Glassmorphic Project Cards
- Top hairline gradient border: subtle red-to-cyan gradient at `15%` opacity.
- Top header featuring project title in `Space Grotesk` (`headline-md`), year badge (`2026`), and GitHub/Demo icon links.
- Inline Metric Grid: High-impact KPI blocks featuring value in `metric-display` font (e.g. `95%`, `0.94 F1`, `60ms`) above a micro-label (`label-sm`).

### 4. Interactive Terminal / Architecture Visualizer
- Darker container `#08090D` with top traffic-light dot controls.
- Monospace output styling for machine learning pipelines (e.g., pipeline ingestion steps, chunking parameters, and vector dimensionality).

### 5. Form Fields & Interactive Inputs
- Canvas background `#0C0E14` with `1px` subtle outline `#1F2433`.
- Active state transitions border to ruby `#FF1E44` with ambient focus ring `rgba(255, 30, 68, 0.15)`.
- Labels in `JetBrains Mono` uppercase with high tracking (`letterSpacing: 0.06em`).
